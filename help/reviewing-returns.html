Reviewing returns

Approve, reject single items, adjust values, and complete returns.

New returns appear on the Returns page. Open one to review it.

Work on many returns at once

On the Returns page, tick the returns you want, then choose Approve, Mark received, or Complete (up to 50 at a time). Vantly asks you to confirm, and tells you about any return it couldn't change.

Approve or reject

Approve return accepts it in Shopify and emails the customer the next steps. Reject closes it and tells the customer why.

To accept only some items, switch those items to Reject in the Items list and give a reason. The button then reads, for example, Approve 1 of 2 items.

Adjust an item's value

Click the pencil next to an item's price to deduct or add an amount (for example, a missing part or a goodwill credit). The reason is saved in the return's history; the customer doesn't see it.

Receive and complete

When the package arrives, mark it received, choose whether to restock each item, then complete the return to issue the refund, store credit, or exchange order.

Green returns

When a rule lets the customer keep the item, there's nothing to ship back. The customer gets a "You can keep it" email and the return goes straight to payout.

Linked returns (different choices per item)

When a customer picks, say, a refund for one item and an exchange for another, you get one return per choice. Each one shows a banner, The customer chose something different for other items, with links to the others. Approve and process each one on its own. They share one box and one label, so marking one received marks the others received too.

The customer gets one email per step for the whole box (requested, approved, label, received); refund, store credit, and exchange emails go out per return. If the exchange costs more than the item it replaces, money from the refund or credit returns in the same box pays toward it first.

Create a return for a customer

Customer called or emailed? Click Create return on the Returns page and find the order. It works like the portal, in three steps:

  1. Items: click Add details on each item the customer is sending back. Finished items show a ✓ and their choice; click Edit to change one.
  2. One screen per item: quantity, reason (or Other (type a reason)), condition, and What the customer gets: exchange (another size or color, or something else), store credit, or refund. Choose Full value, Set an amount ($), or Set a percentage (%), and add an optional note and photos (for example, photos the customer emailed you).
  3. Review: check the items and value, then choose Customer keeps the items, Waive all fees, Flag this return, Needs review, and Email the customer. Click Submit.

It's approved right away unless you turn on Needs review. Items your rules block can still be added; it's noted on the return as an exception. Different choices for different items become linked returns, one per choice.

Restock as a different product

In Settings › Restock as, map a product to another one, for example an opened board back into stock as "Used". Choose whether the mapping applies always, only to opened items, or only to unopened ones. You can upload the mappings as a spreadsheet.

Return destinations

In Settings › Return destinations, add other addresses, like a supplier or a second warehouse. A rule's Where these items go back to sends matching items there, and labels are made out to that address. If a return mixes items for different places, the customer gets one return per destination. Turn off Count these items back into my inventory for drop-ship suppliers.

Bundles

Bundles sold as one product can be returned by their individual items. Set them up in Settings › Bundles. The refund for each item is what the customer paid for the bundle, split by each item's current store price.
