Proposals

When the cart has…, discount these lines…, by: amount, percentage or fixed price.

A proposal is one offer inside a discount. It has two parts.

1. When the cart has

The conditions the cart must meet. Pick a measure (quantity, total, unique products, unique variants, or unique groups), at least or at most, a number, and the group to count in. Add more conditions with Add another group. With no conditions, it applies to every cart.

2. Discount these lines

Pick the group to discount (or every item in the cart), and How many items: leave it empty for all of them, or enter a number to discount only the cheapest ones.

By how much

  • Amount: money off each item, for example $50 off.
  • Percentage: percent off each item, for example 25% off.
  • Fixed price: the item sells for a set price, for example $149.

Turn on Apply to compare-at price to take the discount off the higher compare-at price instead of today's price (never more than today's price).

Use up the matched items

With Use up the matched items on, items counted toward this proposal can't count toward later ones, and with a number in How many items, the offer repeats for every full set in the cart (for example, buy 2 boards and get 1 binding free, for each set).

Message in the cart

Text shown next to the discounted items at checkout. Leave it empty for the default. For codes, Shopify shows the code instead.
