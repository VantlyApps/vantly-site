A discount isn't applying

Test mode, conditions, priority, and what "Needs attention" means.

Work through these in order.

1. Is it live?

A Draft isn't in checkout yet; the discount page lists what's missing (for example, it needs at least one proposal). Scheduled hasn't started; Expired has ended.

2. Is Test mode on?

With Test mode on, only customers tagged test get the discount.

3. Do the conditions fit?

Check customer tags, countries, currencies, B2B, and any required cart attribute. Then check the proposal's "When the cart has" conditions against the cart.

4. Is another proposal winning?

Each item gets at most one product proposal: the first one it fits. Move the one you expect higher, or check whether the item is in the group you think (it joins only the first group it fits unless that's turned off).

5. Does it combine?

If the cart already has another discount, check Combines with on both.

What "Needs attention" means

Vantly couldn't update the discount in Shopify, for example because a group was deleted, a metafield key is missing, it uses more than 100 collections or tags, it's too big for Shopify (see the size meter under Summary), or you're on the Free plan and another discount is already on. Shopify keeps using the last version that worked until you fix it. The discount page says what's wrong.
